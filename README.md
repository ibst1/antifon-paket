# Antifon – nedladdning

Här finns de färdiga versionerna av **Antifon**: inspelning och livetolkning av gudstjänsten till besökarnas mobiler.

**Installera:** hämta `Antifon-<version>-installera.exe` under [Releases](https://github.com/ibst1/antifon-paket/releases/latest)
och kör den. Ingen administratör behövs, och inget annat behöver installeras. En guide i webbläsaren tar dig igenom
resten.

**Uppdatera:** en installerad Antifon söker själv här efter nya versioner och uppdateras med en knapp
(Om → Uppdateringar). Zip-filen är det som uppdateringen hämtar.

Windows kan varna för att filen är okänd (den är inte kodsignerad än): välj *Mer information → Kör ändå*.
